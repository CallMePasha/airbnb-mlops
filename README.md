# Airbnb MLOps

Учебный проект по курсу ML/DLOps на основе данных Inside Airbnb.

## Используемое окружение

- Python 3.11
- VS Code
- Git Bash (терминал)
- uv

## Установка

Установите менеджер зависимостей `uv`:

```bash
pip install uv
```

Из корневой директории проекта выполните:

```bash
uv sync
```

Создайте файл `.env` на основе шаблона `.env.example` и заполните переменные `KEY_ID` и `ACCESS_KEY`:

```bash
cp .env.example .env
```

## Данные

Источник: Inside Airbnb. CSV-файл загружается из S3-совместимого хранилища Yandex Cloud.

## Запуск

1. Откройте `01_read_data.ipynb` в VS Code.
2. Выберите Python-интерпретатор из `.venv`.
3. Последовательно выполните ячейки ноутбука.

При недоступности S3 ноутбук может использовать последнюю сохранённую локальную копию данных `data/train.csv`, если она существует.
